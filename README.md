#  College Database Management System (MySQL)

---

##  *Project Overview*

The **College Database Management System** is a MySQL-based project developed to manage and organize college-related data efficiently.

This project demonstrates practical implementation of relational database concepts including:

* Table creation  
* Data manipulation  
* Constraints  
* Structured SQL queries  

---

##  *Technologies Used*

* MySQL  
* SQL (DDL & DML Commands)  
* Git & GitHub  

---


##  *Database Features*

* Creation of structured tables  
* Implementation of constraints:
  * `PRIMARY KEY`
  * `FOREIGN KEY`
  * `NOT NULL`
  * `UNIQUE`

* Data manipulation using:
  * `INSERT`
  * `UPDATE`
  * `DELETE`

* Data retrieval using:
  * `SELECT`
  * `Conditional queries`  

---

##  *Concepts Practiced*

* Relational Database Design  
* Data Integrity  
* Table Relationships  
* Structured Query Writing  
* Version Control using Git  

---

##  *How to Run This Project*

1. Open MySQL Workbench (or any MySQL client).
2. Create a new database.
3. Import or execute the `College.sql` file.
4. Run the queries to test the database structure.
